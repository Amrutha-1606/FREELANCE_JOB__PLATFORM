# Freelance Job Platform

A simple web-based platform for posting and managing freelance job opportunities using **HTML, CSS, and JavaScript**.

## Features

- Post freelance jobs
- Enter client and job details
- Add required skills
- Set job budget
- View available jobs
- Search jobs
- Delete jobs
- Simple and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run using **Live Server** or open it directly in a browser.
